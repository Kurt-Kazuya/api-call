**API Demonstration**

Requirements Before starting, make sure you have the following installed:
Laravel on your computer (or install Herd for a faster and simpler setup)
Postman Extension for Visual Studio Code

**Setup Instructions**


**FOLLOW THIS STEPS
**
Open the project in Visual Studio Code.

Press Ctrl + J to open the integrated terminal.

Run the following commands one by one:

composer install

copy .env.example .env

php artisan key:generate

php artisan migrate

In the left sidebar of VS Code, select Extensions.

Search for Postman and install the extension.

Sign in to your existing Postman account or create a new one.

Once logged in, the Postman sidebar should appear and be ready to use.

Click the New HTTP Request button (the blue button).

A new tab will open, allowing you to create and send HTTP requests using different request methods (GET, POST, PUT, DELETE, etc.).

You are now ready to test and interact with the API using Postman.
